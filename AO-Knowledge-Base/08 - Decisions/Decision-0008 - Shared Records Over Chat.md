# Decision-0008 - Shared Records Over Chat

Status: Draft  
Version: 0.1  
Owner: Jake Allen  
Last Updated: 2026-06-29

## Purpose

Define how work should move through AI Operator OS.

## Decision

Work should flow through structured records and workflows, not random chat messages.

## Reasoning

Structured records make the system easier to search, audit, hand off, automate, and improve. Random chat messages create hidden context and make operations harder to scale.

## Future Considerations

Future AI interfaces should create or update structured records rather than becoming the primary source of operational truth.
