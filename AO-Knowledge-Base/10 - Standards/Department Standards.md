# Department Standards

Status: Draft  
Version: 0.1  
Owner: Jake Allen  
Last Updated: 2026-06-29

## Purpose

This file will define standards for departments inside AI Operator OS.

Departments should own major business functions and scale through squads and specialized operators.

## Initial Direction

- Departments should have clear ownership.
- Departments should operate through structured records and workflows.
- Departments should avoid becoming isolated chat systems.
- Squads should be added only when the department's workload justifies more structure.
- Operators should perform specialized tasks within clear boundaries.

## Future Evolution

This file should eventually include department charters, squad rules, operator responsibilities, escalation paths, and performance expectations.
