# Coding Standards

Status: Draft  
Version: 0.1  
Owner: Jake Allen  
Last Updated: 2026-06-29

## Purpose

This file will define coding standards for AI Operator OS.

Coding standards should help the codebase remain maintainable, local-first, easy to understand, and safe to extend.

## Initial Direction

- Preserve one permanent codebase.
- Do not create duplicate stores, routes, pages, or persistence systems.
- Reuse existing architecture before adding new patterns.
- Keep domain logic in clear core modules.
- Keep UI connected to active routes and active stores.
- Verify changes with builds before assuming behavior.

## Future Evolution

This file should eventually include naming conventions, testing rules, state-management patterns, error-handling standards, and module organization rules.
