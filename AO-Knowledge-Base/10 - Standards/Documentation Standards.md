# Documentation Standards

Status: Draft  
Version: 0.1  
Owner: Jake Allen  
Last Updated: 2026-06-29

## Purpose

This file will define standards for AI Operator OS documentation.

Documentation should preserve context, decisions, operating knowledge, and implementation guidance for future CEO and Codex sessions.

## Initial Direction

- Document major architectural decisions before implementation whenever practical.
- Keep durable decisions in `08 - Decisions`.
- Keep learned operating knowledge in `09 - Knowledge Growth`.
- Keep standards in `10 - Standards`.
- Keep writing concise, professional, and easy to scan.
- Avoid duplicating the same information in too many places.

## Future Evolution

This file should eventually include templates, review rules, naming conventions, and documentation lifecycle standards.
