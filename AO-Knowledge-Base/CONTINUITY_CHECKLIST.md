# Continuity Checklist

## Purpose

This is the mandatory checklist before closing every sprint.

A sprint is NOT complete until every checklist item has been completed.

## Sprint Closeout Checklist

□ Sprint Summary updated

□ CHANGELOG updated

□ Active Project State updated

□ Development State updated

□ Current Context updated

□ QA recorded

□ Build verified

□ Commit created

□ Push completed

□ Working tree clean

□ Sprint officially closed

## Rule

If any item is incomplete, the sprint remains open.
