# Development Rules

Version: 0.1.0
Last Updated: 2026-06-23

## Roles

- Jake: CEO and final approver
- ChatGPT Project: CTO, architect, and product manager
- Codex: developer
- GitHub: source of truth

## Development Workflow

1. Create issue
2. Define business reason
3. Design architecture
4. Implement code
5. Test
6. Review
7. Commit
8. Update roadmap, changelog, and project memory

## Feature Rule

Every feature must satisfy at least one:

- Make money
- Save time
- Improve decisions
- Automate repetitive work

## Cost Rule

No feature may add recurring cost unless expected ROI is positive.

## Approval Rule

No AI action that impacts clients, money, public communication, or data deletion can execute without human approval.
